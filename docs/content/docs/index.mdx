---
title: Introduction
description: gh-select is a GitHub CLI extension to find, browse and clone GitHub repositories from one terminal screen.
icon: House
---

`gh select` lists all your GitHub repositories in the terminal. Pick one and clone it, open it in your editor, read its README, browse its files or download a release.

```bash
gh extension install remcostoeten/gh-select
gh select
```

![gh select showing a filtered list of repositories](/screens/list.png)

That is all you need to start. It uses your existing `gh` login, so there is nothing to set up.
